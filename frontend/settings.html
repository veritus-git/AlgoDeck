# 01

Katalog Roboczy i Struktura Projektów

Główna przestrzeń dyskowa, w której silnik automatycznie zakłada katalogi poszczególnych zadań, pobiera pliki PDF, generuje pliki źródłowe code.cpp oraz parsuje wejścia/wyjścia testowe.

Katalog tworzony automatycznie przy pierwszym uruchomieniu zadania ze Szkopuła lub Koła MAP.

STRUKTURA FOLDERU ZADANIA (AUTOMATYCZNIE TWORZONA PRZEZ SILNIK) 
{workspace_dir}/
└── koleje/
    ├── code.cpp       # Twój kod źródłowy C++20 z szablonem olimpijskim
    ├── zadanie.pdf    # Oficjalna treść zadania pobrana z serwisu
    ├── testy/         # Pobrane lub wyodrębnione testy wzorcowe
    │   ├── kol1.in    # Dane wejściowe testu 1
    │   ├── kol1.out   # Poprawna odpowiedź testu 1
    │   ├── kol2.in
    │   └── kol2.out
    └── code           # Skompilowana binarka (na Windows: code.exe)

# 05

Automatyzacja Przeglądarki i Sesja Pobrań

Inteligentny nasłuch pobieranych plików z serwisów olimpijskich (Szkopuł, Koło MAP, SIO2). Automatycznie proponuje natychmiastowe utworzenie projektu jednym kliknięciem.

Wykrywaj pobieranie treści zadań (.pdf) i paczek (.zip)

Po pobraniu zadania wyświetla eleganckie okno 1-kliknięcia do natychmiastowego otwarcia zadania w VS Code.

Powiadomienia systemowe pulpitu

Wyświetla powiadomienia systemowe o uruchomieniu środowiska, zakończeniu testów i ewentualnych błędach kompilacji.

Uruchamiaj AlgoDeck przy starcie systemu (Autostart)

Uruchamia usługę AlgoDeck w tle podczas włączania komputera. Gdy opcja jest wyłączona, AlgoDeck startuje wyłącznie na Twoje wyraźne polecenie.

🛡️
Zabezpieczenie przed spamem pobrań (Fresh Session Guard):

Rozszerzenie ignoruje archiwalne pobrania z historii przeglądarki podczas restartu komputera lub uruchamiania przeglądarki. Wykrywane są wyłącznie świeże pobrania wykonane w trakcie aktywnej sesji (okno czasowe 15 sekund).

# 06

Podręcznik Klawiszy Stream Deck i Narzędzie CLI

Oficjalna ściągawka skrótów sprzętowych oraz poleceń terminalowych do pracy w środowisku zawodów.

1. Mapowanie 15 Klawiszy Elgato Stream Deck (Tryb Zadania)

Pozycja Klawisz Etykieta Działanie podczas rozwiązywania zadania
0, 1, 2 Litery Kodu A L G / K O L Skrót nazwy zadania (kliknięcie: otwiera plik code.cpp w VS Code)
3 + Nowe Zadanie Otwiera rozszerzenie / przeglądarkę do załadowania nowego zadania
4 ⚙ Ustawienia Otwiera tę pełnoekranową kartę konfiguracji i architektury
5 ✓ Kompiluj & Testuj Kompiluje code.cpp i w ułamku sekundy wykonuje testy wzorcowe
6 ▶ Uruchom CLI Otwiera interaktywny terminal do ręcznego wpisywania danych
7 ⏹ Zatrzymaj (Kill) Natychmiast przerywa zapętlony program (SIGKILL / TerminateProcess)
8 ⊞ Galeria Zadań Przełącza Stream Deck na menu wyboru zadania
9 = Status Ogólny Prezentuje wynik całościowy: zielone OK, czerwone ANS, pomarańczowe TLE
10 < Poprzedni Test Wybiera poprzedni test z zestawu
11 > Następny Test Wybiera kolejny test z zestawu
12 X / Y Licznik Testów Wskazuje numer aktualnie podglądanego testu (np. 1/4)
13, 14 Detale Testu Wynik / Czas Szczegółowy status wybranego testu (OK, ANS, TLE, MLE) i czas w ms

2. Narzędzie Terminala algodeck (CLI)

Silnik może być w pełni obsługiwany z poziomu dowolnego terminala (Bash, Zsh, PowerShell):

# Uruchomienie daemona silnika w tle (port 8080)
$ algodeck daemon

# Uruchomienie lub weryfikacja czy silnik działa
$ algodeck start

# Sprawdzenie stanu daemona, workspace i Stream Decka
$ algodeck status

# Uruchomienie kompilacji i testów aktywnego zadania
$ algodeck test

# Interaktywne odpalenie programu z konsolą
$ algodeck run

# Autodiagnostyka kompilatorów g++, clang++, VS Code i uprawnień USB
$ algodeck doctor

# Bezpieczne zatrzymanie silnika i zgaszenie Stream Decka
$ algodeck stop
